
### (1) 词相似性 (Word Similarity)

- **目标**：给定一个词，找出词典中和它语义最接近的 Top-k 个词。
    
- **原理**：在高维向量空间中计算距离。最常用的是 **余弦相似度 (Cosine Similarity)**。
    
    $$\text{sim}(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u}^\top \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}$$
    
    - 范围：$[-1, 1]$。1 表示重合，0 表示正交（无关），-1 表示相反。
        
- **例子**：Input: "Chip" $\rightarrow$ Output: "Intel", "Electronics".
    

### (2) 词类比 (Word Analogy)

- **目标**：完成 $a : b :: c : d$ 的推理（即 $a$ 之于 $b$ 相当于 $c$ 之于 $d$）。
    
- **原理**：利用向量空间的线性结构（线性加减）。
    
    $$\vec{d} \approx \vec{b} - \vec{a} + \vec{c}$$
    
- **例子**：
    
    - 语义类比：Beijing - China + Japan $\approx$ Tokyo
        
    - 句法类比：Bad - Worst + Biggest $\approx$ Big

import torch
import torch.nn.functional as F

# 假设我们需要使用的类
class TokenEmbedding:
    def __init__(self, embedding_name='glove.6b.50d'):
        # 实际代码会在这里下载并解析 txt 文件
        # self.idx_to_token: list
        # self.token_to_idx: dict
        # self.idx_to_vec: Tensor [Vocab_Size, Dim]

def knn(W, x, k):
    """
    K近邻搜索：在矩阵 W 中找到与向量 x 最相似的 k 个项
    
    参数:
        W (Tensor): 所有词向量的矩阵，形状 [Vocab_Size, Embed_Dim]
        x (Tensor): 查询词向量，形状 [1, Embed_Dim]
        k (int): 返回前 k 个结果
    """
    # 1. 计算余弦相似度
    # 余弦相似度 = (A . B) / (|A| * |B|)
    
    # 计算 W 中每个向量的模长 (形状: [Vocab_Size, 1])
    # keepdim=True 保证维度方便后续广播计算
    W_norm = W.norm(dim=1, keepdim=True)
    
    # 计算 x 的模长 (形状: [1, 1])
    x_norm = x.norm(dim=1, keepdim=True)
    
    # 计算点积 (矩阵乘法) -> 形状: [Vocab_Size, 1]
    # W: [V, D], x.t(): [D, 1]
    dot_prod = torch.mm(W, x.transpose(0, 1))
    
    # 计算相似度矩阵
    # 加上 1e-9 防止分母为 0
    cosine_sim = dot_prod / (W_norm * x_norm + 1e-9)
    
    # 2. 排序并取 Top-k
    # topk 返回 (values, indices)
    # 这里的 indices 就是词在词表中的 ID
    _, topk_indices = torch.topk(cosine_sim.squeeze(), k=k)
    
    return topk_indices

def get_analogy(token_a, token_b, token_c, embed_model):
    """
    解决类比问题: a : b :: c : ?
    逻辑: vec(d) = vec(b) - vec(a) + vec(c)
    """
    # 1. 获取对应的词向量
    vec_a = embed_model[token_a]
    vec_b = embed_model[token_b]
    vec_c = embed_model[token_c]
    
    # 2. 计算目标向量
    vec_d_target = vec_b - vec_a + vec_c
    
    # 3. 在全词表中搜索最接近 vec_d_target 的词
    # 这里的 knn 应该排除 a, b, c 本身，但为了简化直接搜 Top-k 并在结果中人工排除
    top_indices = knn(embed_model.idx_to_vec, vec_d_target.reshape(1, -1), k=1)
    
    return embed_model.idx_to_token[top_indices[0]]

## 6. CS 学生的课后思考 (算法复杂度)

你可能会注意到笔记最后的练习任务提到了“提升效率”。

- **当前复杂度**：上述 `knn` 函数是暴力计算。假设词表大小 $V=400,000$，维度 $D=300$。每次查询都需要做 $V$ 次点积运算。复杂度为 $O(V \cdot D)$。
    
- **瓶颈**：当 $V$ 达到千万级（工业界规模）时，暴力搜索不可行。
    
- **解决方案 (Approximate Nearest Neighbors, ANN)**：
    
    - **思想**：牺牲一点点精度，换取速度的大幅提升。
        
    - **算法**：
        
        1. **LSH (Locality Sensitive Hashing)**：局部敏感哈希，让相似的向量碰撞到同一个桶里。
            
        2. **HNSW (Hierarchical Navigable Small World)**：基于图的搜索算法，是目前最主流的方法（FAISS 库常用）。
            
    - 这正是你感兴趣的“数据结构与算法”在 AI 里的直接应用。
