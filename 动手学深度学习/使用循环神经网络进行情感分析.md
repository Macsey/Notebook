## 1. 任务背景与数据 (Overview)

- **数据集**：使用的是 **IMDb** 影评数据集。
    
- **任务目标**：二分类问题（正面/负面）。
    
- **数据特点**：文本长度差异大，需要截断或填充。
    

## 2. 数据预处理流程 (Data Pipeline)

在 d2l 的实现中，数据处理分为标准的四个步骤：

1. **分词 (Tokenization)**：
    
    - 将文本句子拆解为单词（Token）。
        
    - 通常去除标点符号，将单词转为小写。
        
2. **构建词表 (Vocabulary)**：
    
    - 统计词频，过滤掉出现频率过低（例如少于 5 次）的单词，将其映射为 `<unk>`。
        
    - 建立 `word -> index` 的映射。
        
3. **序列填充/截断 (Padding/Truncating)**：
    
    - **核心动作**：为了能够进行 Batch 训练，必须将所有句子的长度统一为 `num_steps`（例如 500）。
        
    - **规则**：长于 500 的截断，短于 500 的用 `<pad>` 填充。
        
    - **形状**：处理后的数据形状为 `(Batch Size, Num Steps)`。
        
4. **加载预训练词向量 (Pre-trained Embeddings)**：
    
    - **关键点**：d2l 强调在小数据集（如 IMDb 仅 2.5万条训练数据）上，**必须**使用预训练词向量（如 GloVe）。
        
    - **操作**：将 GloVe 的向量矩阵赋值给 Embedding 层的 `weight`，并设置 `requires_grad=False`（固定）或 `True`（微调）。
        

## 3. 模型架构：BiRNN (Model Architecture)

d2l 采用了一个经典的双向 LSTM 结构。

### 架构图示

### 核心逻辑

1. **Embedding**：输入 `(Batch, Seq)` $\rightarrow$ 输出 `(Batch, Seq, Dim)`。
    
2. **Encoder (Bi-LSTM)**：
    
    - 使用双向 LSTM 处理序列。
        
    - 输出形状：`(Seq, Batch, 2 * Hidden)` (注意 PyTorch 默认 LSTM 输出是 Seq first，除非设置 `batch_first=True`)。
        
3. **Context Extraction (关键点)**：
    
    - 为了捕捉整个句子的情感，我们需要提取**全局特征**。
        
    - **策略**：拼接 **第一个时间步** 和 **最后一个时间步** 的输出。
        
    - **原理**：
        
        - **最后一个时间步 (`outputs[-1]`)**：包含前向 LSTM 读完整个句子的信息 ($\overrightarrow{h}_T$)。
            
        - **第一个时间步 (`outputs[0]`)**：包含后向 LSTM 读完整个句子（从后往前）的信息 ($\overleftarrow{h}_1$)。
            
    - **公式**：$Context = [\text{outputs}[0], \text{outputs}[-1]]$
        
4. **Decoder (FC)**：
    
    - 将拼接后的向量（维度 `4 * Hidden`）输入全连接层进行分类。
        

## 4. 核心代码实现 (PyTorch)

这是 d2l 风格的 `BiRNN` 类实现，不仅包含了模型定义，还包含了特征拼接的细节。



```Python
import torch
from torch import nn

class BiRNN(nn.Module):
    def __init__(self, vocab_size, embed_size, num_hiddens, num_layers, **kwargs):
        super(BiRNN, self).__init__(**kwargs)
        
        # 1. 词嵌入层
        # d2l 中通常不直接在初始化时加载 GloVe，而是在外部加载后赋值
        self.embedding = nn.Embedding(vocab_size, embed_size)
        
        # 2. 编码器：双向 LSTM
        # bidirectional=True 是核心
        self.encoder = nn.LSTM(embed_size, num_hiddens, num_layers=num_layers,
                               bidirectional=True)
        
        # 3. 解码器：全连接层
        # 输入维度是 4 * num_hiddens，原因如下：
        # LSTM 是双向的，单个时间步输出维度是 2 * num_hiddens
        # 我们拼接了“开头”和“结尾”两个时间步的输出，所以是 2 * (2 * num_hiddens) = 4 * num_hiddens
        self.decoder = nn.Linear(4 * num_hiddens, 2)

    def forward(self, inputs):
        # inputs shape: (batch_size, num_steps)
        # LSTM 需要 (seq_len, batch_size, input_size) 的输入，所以这里转置
        # 这里的转置非常关键，因为 nn.LSTM 默认并非 batch_first
        embeddings = self.embedding(inputs.permute(1, 0))
        
        # outputs shape: (num_steps, batch_size, 2 * num_hiddens)
        # 这里的 outputs 包含了每一个时间步的 hidden state
        outputs, _ = self.encoder(embeddings)
        
        # --- d2l 的特征提取核心技巧 ---
        # 拼接 初始时间步(outputs[0]) 和 最后时间步(outputs[-1])
        # outputs[0] 包含了反向LSTM读完整个句子的信息
        # outputs[-1] 包含了正向LSTM读完整个句子的信息
        encoding = torch.cat((outputs[0], outputs[-1]), dim=1)
        
        # encoding shape: (batch_size, 4 * num_hiddens)
        outs = self.decoder(encoding)
        return outs

# ----------------------------
```

## 5. 易错点总结 (Exam/Debug Checklist)

1. **维度陷阱**：
    
    - `nn.LSTM` 默认是 `(Seq, Batch, Feature)`，而数据通常是 `(Batch, Seq)`。**必须使用 `.permute(1, 0)` 转置**，或者在定义 LSTM 时设置 `batch_first=True`（但 d2l 书中代码偏好手动转置以展示原理）。
        
2. **拼接维度**：
    
    - 为什么是 `4 * hidden`？因为拼接了两个时间步（Time Step 0 和 T），每个时间步包含前向和后向两个向量（2 * hidden）。
        
    - **注意**：很多网上的其他教程只取 `outputs[-1]` 或只取 `hidden` 状态，d2l 的这种取法是为了最大化利用上下文信息。
        
3. **预训练向量**：
    
    - 如果不加载 GloVe，仅靠 IMDb 的数据量，模型很难收敛到好的效果（准确率通常卡在 80% 以下，而加上 GloVe 轻松上 85%+）。
