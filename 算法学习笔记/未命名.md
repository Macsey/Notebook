

# 算法笔记：网格翻转与计数 (Grid Flipping)

### 1. 核心思维 (Key Insight)

- **操作的独立性**:
    
    - 按同一个按钮两次 = 没按（偶数次还原，奇数次翻转）。
        
    - 按行的顺序、按列的顺序不影响最终结果。
        
- **对称性 (Symmetry)**:
    
    - 题目问“能否”构成 $K$ 个黑格。
        
    - 关键点：**我们不需要关心具体按了“哪几行”或“哪几列”，只关心按了“多少行”和“多少列”。**
        
    - 原因：无论你按的是第 1 行还是第 2 行，对于总的黑格数量来说，效果是一样的，只是黑格的位置变了。
        

### 2. 数学推导 (Formula Derivation)

假设我们按下了 $i$ 行 和 $j$ 列。

- **总行数**: $N$, **总列数**: $M$
    
- **黑色格子的来源**:
    
    1. **被按下的行** ($i$ 行)：这一行原本全变黑，但其中有 $j$ 个格子因为列也被按了，翻转了两次（黑 $\to$ 白），所以变回白色。
        
        - 该部分贡献黑格：$i \times (M - j)$
            
    2. **被按下的列** ($j$ 列)：这一列原本全变黑，但其中有 $i$ 个格子因为行也被按了（已经在上面讨论过），剩下的 $N - i$ 个格子在未按下的行中，翻转一次变黑。
        
        - 该部分贡献黑格：$j \times (N - i)$
            

**最终公式**:

$$\text{Total Black} = i \times (M - j) + j \times (N - i)$$

> **图解理解**: 想象一个十字架。横着的木头 ($i$ 行) 加上 竖着的木头 ($j$ 列)，中间重叠的地方 ($i \times j$) 因为叠加了两次，如果是异或逻辑（翻转），重叠部分会抵消。

### 3. 复杂度分析

- **暴力枚举 (Brute Force)**:
    
    - 我们需要尝试所有可能的行数 $i$ (从 $0$ 到 $N$)。
        
    - 我们需要尝试所有可能的列数 $j$ (从 $0$ 到 $M$)。
        
- **时间复杂度**: $O(N \times M)$。
    
    - 题目中 $N, M \le 1000$，计算量约为 $10^6$，远小于 1秒 ($10^8$) 的限制，非常安全。
        
- **空间复杂度**: $O(1)$ (不需要额外数组)。

### 4. C++ 代码模板

C++

```
#include <iostream>
using namespace std;

// 变量名说明：
// n, m: 网格大小
// k: 目标黑格数量
// i: 尝试按下的行数
// j: 尝试按下的列数

int main() {
    // 1. 优化输入输出速度 (虽不是必须，但是个好习惯)
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, m, k;
    if (cin >> n >> m >> k) {
        
        // 2. 双重循环枚举：尝试按 0~n 行，0~m 列
        for (int i = 0; i <= n; i++) {
            for (int j = 0; j <= m; j++) {
                
                // 3. 套用公式计算当前黑格总数
                // i * (m - j): 被按行中，没被按列抵消的部分
                // j * (n - i): 被按列中，没被按行抵消的部分
                int current_black = i * (m - j) + j * (n - i);
                
                // 4. 检查是否符合目标
                if (current_black == k) {
                    cout << "Yes" << endl;
                    return 0; // 找到一种情况即可结束
                }
            }
        }
        
        // 5. 遍历完所有情况都没找到
        cout << "No" << endl;
    }
    return 0;
}
```

### 5. 易错点 (Checklist)

1. **循环范围**: 必须包含 $0$ 和 $N/M$。
    
    - `i = 0` 表示一行都不按。
        
    - `i = N` 表示所有行都按（等于把整个网格反色）。
        
    - 漏掉边界会导致 Wrong Answer。
        
2. **公式记忆**: 如果记不住公式，现场画一个 $2 \times 2$ 或 $3 \times 3$ 的格子推导一下：
    
    - 按 1 行 1 列：重叠 1 个。
        
    - 黑格 = (行长) + (列长) - 2 * (重叠) ??? $\to$ 不对，这是集合论加法。
        
    - 翻转问题是：黑格 = (行长 - 重叠) + (列长 - 重叠)。
        

### 6. 扩展思考

如果题目 $N, M$ 很大（比如 $10^5$），$O(NM)$ 会超时怎么办？

- **优化思路**: 固定 $i$（枚举行数），公式变为关于 $j$ 的方程：
    
    $$K = i(M-j) + j(N-i)$$
    
    $$K = iM - ij + jN - ij$$
    
    $$K - iM = j(N - 2i)$$
    
    $$j = \frac{K - iM}{N - 2i}$$
    
- 这样只需要枚举 $i$，算出 $j$，判断 $j$ 是否为整数且在 $[0, M]$ 范围内即可。复杂度降为 $O(N)$。
