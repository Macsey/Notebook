



**题目来源**: 2026蓝桥杯校内训练赛

**难度标签**: 数论、枚举、逆向思维

**时间限制**: 2s

## 1. 题目摘要

给定一个正整数 $N$ ($1 \le N \le 10^{12}$)。

寻找所有的正整数 $m$，使得 $N$ 除以 $m$ 的**商**和**余数**相等。

求所有满足条件的 $m$ 之和。

即满足：

$$\lfloor \frac{N}{m} \rfloor = N \pmod m$$

---

## 2. 破题思路：从暴力到数学

### 初始直觉与瓶颈

最直接的想法是枚举 $m$。

- 我们从 $m=1$ 循环到 $N$。
    
- 检查是否满足 `N / m == N % m`。
    
- **瓶颈**：$N$ 最大可达 $10^{12}$。$O(N)$ 的算法会跑数万年，必定 **TLE (超时)**。我们需要一个 $O(\sqrt{N})$ 级别的解法。
    

### 核心切入点：回归定义

当题目涉及“商”和“余数”时，第一反应应该是写出**除法定义式**（带余除法）：

$$\text{被除数} = \text{除数} \times \text{商} + \text{余数}$$

在本题中，设商为 $q$，余数为 $r$。

$$N = m \cdot q + r$$

**关键条件**：题目说商等于余数，即 $q = r$。

将 $r$ 替换为 $q$，公式变形为：

$$N = m \cdot q + q$$

提取公因式 $q$：

$$N = q(m + 1)$$

### 逆向思维

如果我们继续找 $m$，还是很困难。但是观察上面的公式：$N$ 是已知的，式子变成了 $N$ 的因数分解形式。

$$m + 1 = \frac{N}{q} \implies m = \frac{N}{q} - 1$$

**与其在浩瀚的范围内寻找 $m$，不如去寻找 $q$（商）。**

只要确定了 $q$，就能算出 $m$。

那 $q$ 的范围是多少呢？这里有一个**隐形限制**：

在除法中，**余数必须小于除数**。

即 $r < m$。

因为本题 $r=q$，所以必须满足：

$$q < m$$

将 $m = \frac{N}{q} - 1$ 代入不等式：

$$q < \frac{N}{q} - 1$$

$$q + 1 < \frac{N}{q}$$

$$q(q + 1) < N$$

**结论**：$q$ 的大小大致在 $\sqrt{N}$ 级别。对于 $N=10^{12}$，$q$ 只需枚举到 $10^6$，这是计算机可以瞬间完成的。

---
## 3. 算法流程

1. **遍历变量**：枚举商 $q$，从 1 开始。
    
2. **循环边界**：当 $q(q+1) \ge N$ 时停止循环（由不等式 $q < m$ 推导而来）。
    
3. **整除性检查**：根据 $N = q(m+1)$，$N$ 必须能被 $q$ 整除。
    
    - 如果 `N % q == 0`，则计算 $m = \frac{N}{q} - 1$。
        
    - 此时算出的 $m$ 一定满足 $m > q$，是合法解。
        
4. **累加结果**：将 $m$ 加入总和。

## 4. AC 代码 (C++)



```C++
#include <iostream>

using namespace std;

// 必须使用 long long，因为 N 高达 10^12，结果 ans 也会超过 int 范围
using ll = long long;

int main() {
    ll N;
    if (!(cin >> N)) return 0;

    ll ans = 0;

    // 核心思路：枚举商 q
    // 循环终止条件推导：
    // 因为余数必须小于除数 -> q < m
    // 代入 m = N/q - 1 -> q < N/q - 1 -> q(q+1) < N
    for (ll q = 1; q * (q + 1) < N; ++q) {
        
        // N = q(m+1)，说明 N 必须是 q 的倍数
        if (N % q == 0) {
            // 反解出 m
            ll m = N / q - 1;
            
            // 此时 m 一定是合法的（满足 m > q 且能构造出商为 q）
            ans += m;
        }
    }

    cout << ans << endl;

    return 0;
}
```

## 5. 启发与总结 

1. **除法题的万能公式**：
    
    遇到涉及 `N / m` 和 `N % m` 的题目，**永远先写出 $N = m \cdot q + r$**。这是解题的钥匙。
    
2. **主元变换（枚举对象的转换）**：
    
    当枚举除数 $m$ ($1 \to N$) 会超时时，尝试枚举商 $q$。
    
    - 因为 $m \times q \approx N$，如果 $m$ 很大，那么 $q$ 一定很小。
        
    - 通常这就是 $O(N) \to O(\sqrt{N})$ 优化的核心手段。
        
3. **不等式约束**：
    
    永远不要忘记除法的基本定义：**余数 < 除数**。这往往是确定枚举边界的关键。
    
4. **数据类型警觉**：
    
    看到 $N \le 10^{12}$，**必须**使用 `long long` (C++) 或 Python (自动处理大数)，否则连样例 2 都过不了。
